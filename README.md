# open-computer-use-lite

> **Status: idea.** No code yet.

## The problem

[iFurySt/open-computer-use](https://github.com/iFurySt/open-computer-use) is
a great project. It works well with large and medium-sized models such as
GPT-4, Claude, DeepSeek and others.

Small models (≤7B), however, can't handle full computer use: they manage
simple steps but fall apart on complex tasks.

## What's planned

`open-computer-use-lite` is an attempt to find a way for small models to
drive a computer as confidently as large ones do.

The specific approach — optimizing the original for weak models or building
a separate implementation from scratch — is still being decided. For now
it's just an idea: let's see what comes of it.
